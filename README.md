# 👜 bag-price-calculator - LE Brand

Professional pricing calculator for my crochet bag business @le_official_brand

## What does it do?
This calculator helps me price my handmade crochet bags correctly.
It calculates:
- Real cost (yarn + labour + packaging)
- Profit
- Profit margin %

## Why I made it?
So I don't underprice my work and I can grow LE Brand as a real business.

## How to use it?
1. Open `bag_price_calculator.py`
2. Run it
3. Enter yarn cost, hours, and selling price
4. It will show you your profit!
